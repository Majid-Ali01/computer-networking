# 💻 Windows CMD Toolkit

<div align="center">

|     Command     | Purpose                                |
| :-------------: | -------------------------------------- |
|    `ipconfig`   | 🌐 View IP configuration               |
|      `ping`     | 📡 Test network connectivity           |
|    `tracert`    | 🗺️ Trace the route to a destination   |
|    `hostname`   | 🖥️ Identify the computer hostname     |
|    `nslookup`   | 🔎 Query DNS information               |
| `ipconfig /all` | 📋 View detailed network configuration |
